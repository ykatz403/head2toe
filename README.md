# Head2Toe

See a full head-to-toe outfit on a 3D avatar built from your own one-time body scan, then shop every piece.

## Planned stack

- **Frontend:** React + TypeScript (Vite), three.js for the 3D avatar, in-browser body measurement from photos
- **Backend:** ASP.NET Core Web API, SQLite in development
- **Payments:** Stripe (Plus subscription)
- **Revenue:** affiliate links first, then Plus subscription, sponsored placements, retailer widget

## Layout

```
prototype/   single-page demo used for stakeholder review (static HTML)
src/         (coming) api/ and web/
```

## Status

Early. `prototype/head2toe-demo.html` is the proof of concept: 3D avatar, season and budget questions, shop panel, simulated scan flow, revenue calculator.
